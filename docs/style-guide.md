# 样式规范

[English](./style-guide.en.md)

本文记录 `next-supabase-scaffold` 的视觉规则。页面采用克制的开发者控制台方向，
认证字段、校验、状态反馈和可访问性属于不可削弱的稳定核心。

## 1. 设计方向

- 近黑中性色表面搭配绿色认证信号，蓝色与琥珀色只用于辅助状态。
- 首页首屏直接展示项目名和本地 HTML/CSS 认证请求管线，不依赖外部图片或抽象 SVG。
- 首页说明已完成的基础设施，不虚构业务数据或功能。
- 私有工作台保持安静、可扫描，用于展示认证边界和业务接入顺序。
- 页面章节保持完整宽度和清晰边界；卡片只用于重复能力项或真实状态项。

## 2. 设计令牌

令牌统一定义在 `src/app/globals.css` 的 `:root`：

- `--background`、`--foreground`：页面底色与正文。
- `--card`、`--popover`：面板与浮层表面。
- `--primary`：认证成功、主要操作和连接状态。
- `--muted`、`--muted-foreground`：次级表面与说明文字。
- `--border`、`--input`、`--ring`：边界、输入框和焦点。
- `--font-ui`、`--font-display`、`--font-code`：正文、展示和代码字体。
- `--app-shadow-*`：认证卡片与终端面板阴影。

业务组件优先使用语义类，不散落无语义颜色。

## 3. 字体

- 正文：Avenir Next、Segoe UI、PingFang SC。
- 展示标题：Iowan Old Style、Songti SC、Georgia。
- 项目名、状态、路径与代码：SFMono-Regular、Consolas。
- 字号使用固定层级，只在 980px 与 640px 断点切换。
- 正文行高不低于 `1.6`，中文多行展示标题行高不低于 `1.1`，避免断行后文字重叠。
- 字距保持 `0` 或正值，长项目名允许自然换行。

## 4. 布局

- 页面最大内容宽度为 `1440px`。
- 桌面首页导航使用左侧品牌、中间菜单、右侧操作的三列结构。
- 首页导航吸附在视口顶部，滚动时使用不透明背景保持内容可读。
- 桌面留白使用 `clamp()`；移动端至少保留 `12px`。
- 响应式只使用 `980px` 和 `640px` 两级断点。
- 首页首屏在桌面和移动端都露出状态栏内容。
- 固定控件声明稳定高度，动态状态不得推动相邻布局。

## 5. 控件

- 交互目标不小于 `44px`。
- 图标统一使用 Lucide；纯图标按钮必须提供可访问名称。
- 关联内容面板切换使用 `Tabs`；布尔同意使用 Checkbox。
- 链接按钮使用 `buttonVariants()`，保留原生链接语义。
- 所有禁用态必须同时阻止事件并提供视觉反馈。

## 6. 表单

- 使用 `FieldGroup`、`Field`、`FieldLabel` 和 `FieldError`。
- 输入组合使用 `InputGroup`，密码显隐按钮保留可访问名称。
- 邮箱验证码发送操作使用原生文字链接，与“邮箱”标签同排并右对齐；输入框独占下一行。
- 错误通过 `aria-invalid` 与 `aria-describedby` 关联。
- 邮箱验证码固定 6 位数字，支持 `one-time-code`，重发冷却为 60 秒。
- 登录和注册保留条款同意、提交态、错误本地化和密码强度反馈。

## 7. 动效

- 优先使用 CSS，只动画 `transform` 和 `opacity`。
- 页面进入动效保持短促，不对表单字段添加持续装饰动画。
- `prefers-reduced-motion: reduce` 下关闭页面进入与悬停位移动效。
- 不为简单效果新增动画运行时依赖。

## 8. 可访问性

- 页面保持语义标题层级和键盘顺序。
- Tabs 使用完整 `tablist`、`tab` 与 `tabpanel` 关系。
- 焦点态清晰，不能只依赖颜色表达状态。
- 装饰图像与图形使用 `aria-hidden`，内容图像提供有效替代文本。
- 交付前检查 390px 移动端与宽桌面视口的溢出、遮挡和断行。
